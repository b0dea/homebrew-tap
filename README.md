# b0dea/homebrew-tap

Homebrew formulas for [b0dea](https://github.com/b0dea) projects.

```sh
brew install b0dea/tap/fortkeep
```

| Formula | What |
|---|---|
| `fortkeep` | [fortkeep](https://github.com/b0dea/fortkeep): a security checkup for developer Macs, run with your coding agent. |

Each formula is copied from its project's `packaging/homebrew/` when a release is published, with that release's pins.
